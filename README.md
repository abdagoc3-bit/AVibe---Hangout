# AVibe - Hangout
A web application for planning hangouts and dates effortlessly with real-time Firebase Firestore saving.

# Key Features:

**Interactive Selection for Venue, Date, and Time:** 
- Easily pick spots like Cafes, Museums, Parks, or Malls. The exact address of the chosen place will also be displayed.
- Date Selection: 
- Time selection: once selected, the time duration will be displayed.

**Custom Venues & Addresses:** If your desired place is not on the list, you can just choose "Other" and type in your own specific locations and spots.

**Activity & Companion Tracker:** Select multiple activities and track your companions for the day.

**Instant Cloud Storage:** Automatically saves and syncs all responses in real time using Firebase Firestore.

# Built With:
- HTML5 & CSS3
- Vanilla JavaScript
- Firebase Firestore (Database)
